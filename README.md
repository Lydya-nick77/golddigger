# golddigger

Golddigger is a chocobo digging tracker for Ashita v4 based on hgather.
Starting at v0.5.0, the addon is focus on Phoenix XI and retail.

## Commands

- /golddigger
- /gd
- /golddigger config
- /golddigger clear

## Notes

- Golddigger tracks dig attempts, items, fatigue pacing, moon, weather, and recent rewards.
- Reward output is count-based only; the addon does not calculates gil values or item prices.
- Shows cooldown for Zone delay and between each dig.
- Shows countdown for next elemental ore window.
- Progression uses integer Wing Skill levels. Every obtained item awards XP according to its configured Phoenix item rank, and the panel shows current-level XP progress.
