# golddigger

Golddigger is a chocobo digging tracker for Ashita v4 based on hgather.

## Commands

- /golddigger
- /gd
- /golddigger config
- /golddigger clear

## Notes

- Golddigger tracks dig attempts, items, fatigue pacing, moon, weather, and recent rewards.
- Reward output is count-based only; the addon no longer calculates gil values or item prices.
- Shows cooldown for Zone delay and between each dig.
- Shows countdown for next ore window.
